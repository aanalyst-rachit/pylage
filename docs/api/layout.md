# Layout & Navigation API

Canonical URI: `/api/layout/`

Layout APIs compose components into rows, columns, containers, application shells, navigation regions, and other structural layouts.

## Core layout

The core layout helpers are:

- `pl.row`
- `pl.column`
- `pl.center`
- `pl.container`
- `pl.grid`
- `pl.stack`
- `pl.split`
- `pl.two_column`
- `pl.three_column`

## Application structure

- `pl.header`
- `pl.footer`
- `pl.topbar`
- `pl.top_header`
- `pl.app_shell`

## Navigation

- `pl.navbar`
- `pl.navigation`
- `pl.navigation_controls`
- `pl.sidebar_layout`
- `pl.menu`
- `pl.tabs`
- `pl.pagination`
- `pl.breadcrumb_trail`

For drawer-based navigation, see the dedicated [Drawer documentation](../component/drawer.md).
