# 1. 🎯 FINAL VISION

PySkin ka goal ek aisa **Python-first UI framework** banana hai jisme developer primarily **Python** likhe aur framework automatically UI ko browser/desktop par render kare.

Target experience:

```python
import pyskin as ps

count = ps.State(0)

app = ps.Column(
    ps.Heading("Counter"),
    ps.Text(count),
    ps.Button("+", on_click=lambda: count.set(count.value + 1)),
)

ps.run(app)
```

Developer ko:

```text
❌ HTML
❌ CSS
❌ JavaScript
❌ DOM manipulation
❌ WebSocket management
```

manually handle nahi karna chahiye.

Framework internally ye sab handle kare.

---

# 2. 🧠 CORE PHILOSOPHY

PySkin ka architecture:

```text
Python Developer
       ↓
Python UI API
       ↓
Component Tree
       ↓
Registry / Metadata
       ↓
UI IR
       ↓
Compiler / Optimizer
       ↓
Runtime
       ↓
Tiny Client Runtime
       ↓
Browser / Desktop
```

Important:

> **No user-written JavaScript ≠ zero JavaScript internally.**

Browser ke liye ek tiny internal JS runtime allowed hai.

Goal hai:

```text
Developer → Python only
Framework → JS internally
```
