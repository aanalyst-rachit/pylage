# PU / PySkin — Updated Master Blueprint / Checkpoint

**Project:** PySkin — Python-first Universal UI Framework
**Long-term vision:** PU / Python Universal UI Framework

> Python developers ko sirf Python se lightweight, reactive Web + Desktop UI banana — user ko HTML/JavaScript likhne ki zarurat na ho.

---

## 1. Core Vision

```text
Python Code
    ↓
PySkin / PU UI API
    ↓
UI Tree / IR
    ↓
Compiler / Optimizer
    ↓
HTML/CSS + Tiny Client Runtime
    ↓
Web / Desktop
```

Main differentiators:

* Python-first UI
* No user-written HTML
* No user-written JavaScript
* Lightweight client runtime
* Persistent Python runtime
* WebSocket event/state bridge
* Fine-grained reactive updates
* Low startup latency
* Low memory footprint
* Future: same architecture → Web + Desktop + potentially Mobile

**Important:** “No JavaScript” means developer ko JS nahi likhna padega; framework ke internal runtime mein tiny JS allowed hai.


### Important architectural limitation

Renderer currently contains component-specific logic:

```python
if component_type == "Column":
if component_type == "Heading":
if component_type == "Button":
```

This is acceptable for the prototype.

Eventually this should evolve toward:

```text
Component / Node
       ↓
IR
       ↓
Compiler
       ↓
Renderer
```

without destroying current compatibility.
